# Updating the Atmosphere System

> As of July 29, 2022, a reasonably reliable tutorial was available on this [blog](https://shipengliang.com/games/switch-%e5%a4%a7%e6%b0%94%e5%b1%82-atmosphere-%e5%a6%82%e4%bd%95%e7%a6%bb%e7%ba%bf%e5%8d%87%e7%ba%a7%e7%b3%bb%e7%bb%9f.html). Downloads from that site are slow, however, so I recommend using it only to download the [latest version of Atmosphere](https://shipengliang.com/games/%e5%a4%a7%e6%b0%94%e5%b1%82-atmosphere-%e6%9c%80%e6%96%b0%e7%89%88-%e5%8e%86%e5%8f%b2%e7%89%88-%e4%b8%8b%e8%bd%bd.html). Download the required firmware by searching Google for the specific version. I verified that the Chinese firmware release works.

## Prepare Atmosphere and the System Firmware

Each Atmosphere release supports corresponding Nintendo Switch firmware versions. In general, look for the firmware supported by the latest Atmosphere release.

After downloading the Atmosphere package, extract its files directly to the root of the TF card. I usually replace the files one by one according to what is already on the card.

System firmware normally comes as an archive. Extract it into a folder, and then copy the entire folder to the root of the TF card.

## Update the System

I previously used ChoiDujourNX for system updates, but later switched to Daybreak.

During the update, simply select the system-firmware folder copied to the root of the TF card in the previous step. Be sure to install the exFAT driver; otherwise, the system cannot read TF cards larger than 32 GB.

If you accidentally omit the exFAT driver, the device will show only a black screen at startup. The fix is straightforward: format a small card as FAT32, copy the Atmosphere system files to its root as in the first step, copy the system firmware, enter the system, and run the update again.

## Potential Problems

After a major version update, previously downloaded games often stop opening and must be reinstalled.

To enable cheats by default, delete `atmosphere\config\system_settings.ini` and restart the device.
