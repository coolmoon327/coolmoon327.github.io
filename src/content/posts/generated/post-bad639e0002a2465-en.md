# Code Server

### 1. Install Dependencies

- Most servers do not need these packages installed; they are mainly dependencies for background services.

```
sudo apt install curl wget vim clang gcc python -y
curl -sL https://deb.nodesource.com/setup_12.x | sudo -E bash -
sudo apt-get install -y nodejs
sudo npm install -g yarn
```

### 2. Run the Official Script to Install Code Server Directly

```
curl -fsSL https://code-server.dev/install.sh | sh
```

### 3. Configure `~/.config/code-server/config.yaml`

- If this file does not exist, run `code-server` once first.
- Change `bind-addr` to `[address removed]:target-port`.
- Set `password` to the desired password.

### 4. Run Code Server

- Run it in the background:

```
code-server &
```

- Run it as a service:

```
sudo systemctl start code-server@$USER
sudo systemctl restart code-server@$USER
sudo systemctl stop code-server@$USER
```

- Enable the service at startup:

```
sudo systemctl enable code-server@$USER
```

- Uninstall code-server:

```
sudo systemctl stop code-server@$USER
rm -rf /usr/lib/code-server
rm -rf ~/.local/share/code-server
rm -rf ~/.config/code-server
```
