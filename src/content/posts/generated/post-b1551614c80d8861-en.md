# Theoretical Foundations

## Markov Property

Deep reinforcement-learning algorithms assume that the problem has the Markov property, or no aftereffect; in other words, the problem must be modeled as an MDP.

In a discrete state space, the Markov property follows when the space is **reachable, irreducible, and aperiodic**, and a random walk through the state space converges to a stationary distribution. We can then split a complete non-IID trajectory $ \tau = (s\_0, a\_0, s\_1, a\_1, …, s\_T, a\_T)$ into tuples $ (s\_t, a\_t, r\_t)$ to construct a batch for model training.

Under the Markov property, the objective can be written using the **stationary distribution** dπ(s)d^{\pi}(s)dπ(s):

J(π)=∫Sdπ(s)Eπ[∑t=0∞γtRt+1]dsJ(\pi)=\int\_{\mathcal{S}} d^{\pi}(s) \mathbb{E}\_{\pi}\left[\sum\_{t=0}^{\infty} \gamma^{t} R\_{t+1}\right] d s
J(π)=∫S​dπ(s)Eπ​[t=0∑∞​γtRt+1​]ds

This objective differs somewhat from the one commonly used because it is more rigorous: it includes the initial-state distribution in addition to the value function. When the Markov property holds, maximizing the value function alone is effectively sufficient, which is how later objectives are written. Without the Markov property, earlier actions influence action selection in the current state. This usually implies unstable environmental transitions—the action chosen in the current state must account for a sequence of prior states—making the value function difficult to use as the optimization objective. Perhaps a sequential model is more suitable in this case.

Many reinforcement-learning derivations also depend on the Markov property, including TD methods and simplified objectives. Monte Carlo methods might replace the former, but the latter directly affects the derivation of policy gradients. The gradient must be rederived for each concrete problem encountered by policy-based algorithms in this setting.

The probability pθ(τ)p\_{\theta}(\tau)pθ​(τ) of a trajectory τ\tauτ in reinforcement learning can be written as:

The gradient of the objective with respect to the policy is therefore:

## Gaussian Policy

For a discrete action space, a neural network fits a multinomial distribution—the probability of taking each action. For a continuous action space, the network fits a probability density function; action values follow its corresponding distribution, and the network fits the distribution's principal parameters. A typical example fits the mean μθ\mu\_\thetaμθ​ and variance σθ\sigma\_\thetaσθ​ of a Gaussian density:

πθ(at∣st)=12πσθ(st)exp⁡(−(at−μθ(st))22σθ2(sθ))\pi\_\theta(a\_t \mid s\_t)=\frac{1}{\sqrt{2 \pi} \sigma\_\theta(s\_t)} \exp \left(-\frac{(a\_t - \mu\_\theta(s\_t))^{2}}{2 \sigma\_\theta^{2}(s\_\theta)}\right)
πθ​(at​∣st​)=2π​σθ​(st​)1​exp(−2σθ2​(sθ​)(at​−μθ​(st​))2​)

The example in CS 285 uses a simplified Gaussian policy in which the neural network fits only the mean. In practice, calculate the derivative of the log density with respect to the policy for whichever probability density is used, then substitute it into the objective's gradient expression to update the policy. In a neural network, terms related to ∇θμθ\nabla\_\theta \mu\_\theta∇θ​μθ​ and ∇θσθ\nabla\_\theta \sigma\_\theta∇θ​σθ​ are generally the gradient values that must be backpropagated through the corresponding parts of the network.

## Variance Problem

Depending on the reward function's design—even a change in the magnitude of a constant in that function—the same RL algorithm trained with the same model in the same environment can exhibit severe variance. The policies may eventually converge to similar solutions, but their training processes can differ dramatically. In a finite training run, the model may not get close enough to convergence and may therefore perform poorly. We would like a model far from convergence to reflect the eventual converged distribution to some extent, but the variance of policy-gradient algorithms makes that impossible.

In real applications, this variance must be reduced before policy-gradient algorithms can be used.

First, recall that the purpose of the policy gradient is to modify the policy for selecting an action according to the reward caused by that action. By causality, an action chosen in the current state cannot affect past rewards. We can therefore modify the policy-gradient expression by removing rewards from before the time corresponding to each log derivative. In the ttt-th summand, only rewards with t≤t′≤Tt \leq t' \leq Tt≤t′≤T are added—the estimate of the state-action value at time ttt. After all, **reducing the number of terms in the sample sum reduces variance**:

∇θJ(θ)≈1N∑i=1N∑t=1T∇θlog⁡πθ(ai,t∣si,t)(∑t′=tTr(si,t′,ai,t′))=1N∑i=1N∑t=1T∇θlog⁡πθ(ai,t∣si,t)Q^i,t\nabla\_{\theta} J(\theta) \approx \frac{1}{N} \sum\_{i=1}^{N} \sum\_{t=1}^{T} \nabla\_{\theta} \log \pi\_{\theta}\left(\mathbf{a}\_{i, t} \mid \mathbf{s}\_{i, t}\right)\left(\sum\_{t^{\prime}=t}^{T} r\left(\mathbf{s}\_{i, t^{\prime}}, \mathbf{a}\_{i, t^{\prime}}\right)\right)\\
= \frac{1}{N} \sum\_{i=1}^{N} \sum\_{t=1}^{T} \nabla\_{\theta} \log \pi\_{\theta}\left(\mathbf{a}\_{i, t} \mid \mathbf{s}\_{i, t}\right) \hat{Q}\_{i, t}
∇θ​J(θ)≈N1​i=1∑N​t=1∑T​∇θ​logπθ​(ai,t​∣si,t​)(t′=t∑T​r(si,t′​,ai,t′​))=N1​i=1∑N​t=1∑T​∇θ​logπθ​(ai,t​∣si,t​)Q^​i,t​

Second, since a constant in the reward function can cause variance—and when all rewards are positive, even poor actions are encouraged before training is sufficient—we can center the reward function by taking a baseline value as zero and measuring other rewards relative to it. This can reduce variance substantially without changing the gradient's mean. It is known as the baseline method:

∇θJ(θ)≈1N∑i=1N∇θlog⁡pθ(τ)[r(τ)−b]\nabla\_{\theta} J(\theta) \approx \frac{1}{N} \sum\_{i=1}^{N} \nabla\_{\theta} \log p\_{\theta}(\tau)[r(\tau)-b]
∇θ​J(θ)≈N1​i=1∑N​∇θ​logpθ​(τ)[r(τ)−b]

There are many possible choices for bbb. The simplest is b=1N∑i=1Nr(τ)b=\frac{1}{N} \sum\_{i=1}^{N} r(\tau)b=N1​∑i=1N​r(τ). Although not optimal, it is the **most practical**. Taking the variance of the expression above and then differentiating that variance gives the optimal bbb:

b=E[g(τ)2r(τ)]E[g(τ)2]b = \frac{ E\left[g(\tau)^{2} r(\tau)\right]} {E\left[g(\tau)^{2}\right]}
b=E[g(τ)2]E[g(τ)2r(τ)]​

Here, g denotes the log-derivative term in the gradient equation. The optimal value would require a separate baseline for every gradient dimension, so using the mean as the baseline is more convenient. When the relevant gradient term is expressed with Q, a mean baseline b is the value function V, and Q - b is the advantage A = Q - V.

## Off-Policy Problem

The policy-gradient equation above is on-policy: every change in the policy requires resampling multiple trajectories to calculate the gradient under the current policy, which is highly inefficient. Importance sampling can instead produce an off-policy objective:

J(θ)=Eτ∼pˉ(τ)[pθ(τ)pˉ(τ)(τ)]J(\theta)=E\_{\tau \sim \bar{p}(\tau)}\left[\frac{p\_{\theta}(\tau)}{\bar{p}(\tau)}(\tau)\right]
J(θ)=Eτ∼pˉ​(τ)​[pˉ​(τ)pθ​(τ)​(τ)]

pθ(τ)=p(s1)∏t=1Tπθ(at∣st)p(st+1∣st,at) p\_{\theta}(\tau)=p\left(\mathbf{s}\_{1}\right) \prod\_{t=1}^{T} \pi\_{\theta}\left(\mathbf{a}\_{t} \mid \mathbf{s}\_{t}\right) p\left(\mathbf{s}\_{t+1} \mid \mathbf{s}\_{t}, \mathbf{a}\_{t}\right)
pθ​(τ)=p(s1​)t=1∏T​πθ​(at​∣st​)p(st+1​∣st​,at​)

pθ(τ)pˉ(τ)=∏t=1Tπθ(at∣st)∏t=1Tπˉ(at∣st)\frac{p\_{\theta}(\tau)}{\bar{p}(\tau)}=\frac{\prod\_{t=1}^{T} \pi\_{\theta}\left(\mathbf{a}\_{t} \mid \mathbf{s}\_{t}\right)}{\prod\_{t=1}^{T} \bar{\pi}\left(\mathbf{a}\_{t} \mid \mathbf{s}\_{t}\right)}

This allows old experience or data from other sources to train the current RL algorithm. Perform importance sampling for policy θ′\theta'θ′ on samples from a known policy θ\thetaθ, then differentiate with respect to θ′\theta'θ′:

At this point, policy gradients have addressed how to use off-policy data. Importance sampling itself still has a limitation: when the two distributions differ greatly, its variance becomes large and more samples are needed for good results.

In addition to off-policy methods, **A3C addresses slow on-policy convergence through multithreading**. If the problem with on-policy training is insufficient sample-collection speed, many agents can explore the same environment and pool their experience for on-policy training, compensating for the lack of data from a single sampling run.

## Descent-Direction Problem

Policy-gradient algorithms have a serious step-size problem: a unit step in different gradient components does not have the same effect on the objective. This resembles steepest descent in convex optimization. Both choose the best descent direction only at the current iterate while ignoring how far that direction deviates from the target point. The full descent trajectory can wind toward the optimum, taking many detours and ultimately converging very slowly. In RL, this can also be stated as a need for different learning rates in different components of the descent direction. A single learning rate may cause some components to pass the optimal policy before others have reached it.

Convex optimization offers several ways to address the descent-direction problem, including Newton's method, conjugate-space methods, and trust-region methods. The mainstream policy-gradient solution is the trust-region method: constrain the distance between consecutive iterates, or equivalently the change between policies before and after the update. The simplest constraint requires the Euclidean distance between the two policies to be sufficiently small:

θ′←arg⁡max⁡θ′(θ′−θ)T∇θJ(θ)s.t.∥θ′−θ∥2≤ϵ\theta^{\prime} \leftarrow \arg \max \_{\theta^{\prime}}\left(\theta^{\prime}-\theta\right)^{T} \nabla\_{\theta} J(\theta) \quad s.t. \left\|\theta^{\prime}-\theta\right\|^{2} \leq \epsilon

With the classic KL divergence, for example, we can approximate it using the Fisher information matrix (FIM):

## Bias-Variance Trade-Off

Using an entire trajectory to calculate a policy gradient, as above, is also called the Monte Carlo method. In essence, one sample of the state-action value Q stands in for Q, so it has high variance:

∇θJ(θ)≈1N∑i=1N∑t=1T∇θlog⁡πθ(ai,t∣si,t)(∑t′=1Tr(si,t′,ai,t′)−b)\nabla\_{\theta} J(\theta) \approx \frac{1}{N} \sum\_{i=1}^{N} \sum\_{t=1}^{T} \nabla\_{\theta} \log \pi\_{\theta}\left(\mathbf{a}\_{i, t} \mid \mathbf{s}\_{i, t}\right)\left(\sum\_{t^{\prime}=1}^{T} r\left(\mathbf{s}\_{i, t^{\prime}}, \mathbf{a}\_{i, t^{\prime}}\right)-b\right)

We can instead maintain an estimator of Q and use it to construct an advantage function, although estimation may introduce bias:

In summary, the advantage function reduces variance effectively but introduces bias. Directly using Q is unbiased, but whether we use Monte Carlo or TD, we actually calculate the gradient with an estimate of Q, which has variance. **If Q is not estimated and an estimate of V is used as the baseline, the result is an unbiased policy-gradient algorithm with low variance.**

It is worth mentioning that the advantage equation is **not commonly used in practice**. Q can be used directly in the gradient. Although variance is higher, it works well with minibatches and is unbiased.

## Bootstrapping

This idea gave rise to TD algorithms, which train more efficiently than Monte Carlo methods but can likewise introduce bias through function fitting.

It is called bootstrapping because the current V estimate is used to estimate the updated V—the second V term in y. A method that updates itself, or transforms itself into its own optimization target, is a bootstrap.

# Actor-Critc

The actor trains the policy, while the critic fits the value function: V is fitted on-policy, and Q is fitted off-policy.

The traditional approach fits a value function from samples and then uses it to calculate the policy gradient. Its main advantage is lower policy-gradient variance. DDPG and DQN introduce neural networks into the value-function component of this framework and use target networks to further address off-policy learning.

## Off-Policy Learning with an Experience Replay Buffer

[Image omitted: third-party image]

Using experience data clearly introduces an off-policy problem. The traditional solution is importance sampling, but actor-critic algorithms can address it in other ways.

The off-policy effect arises because experience data contains actions selected by old policies. Updating V from this data is unreliable because s -> r depends on both the environment and the policy. Updating Q does not depend on the policy—s, a -> r depends only on the environment—and the action in Q(s’, a’) during bootstrapping can be sampled from the **current policy**. A Q-based algorithm can therefore solve the off-policy problem in the actor. Put differently, a **Q-based Bellman equation does not care how an action was selected**. The same idea is used to sample the action in the gradient expression from the **current policy**, and Q is used directly instead of the advantage function. Overall, the method uses only s’ and r from experience to update Q, then uses Q and s from experience to calculate the gradient.

The result is still biased because the distribution of s—the stationary probability—comes from the old policy, but this simply means finding the optimal policy over a broader distribution. The reinforcement-learning objective can be viewed as finding the optimum under pθ(s)p\_\theta(s)pθ​(s). Replacing V with Q also makes the critic's result too large. In DQN and DDPG, the critic's Q output is consistently larger than the true value because Q-learning has a **maximization bias**. The underlying reason is that the **expected maximum of samples is greater than or equal to the maximum of the expectation**. Double Q is the classic solution.

When updating the critic, TD3 also adds a small perturbation to the action in target Q(s’, a’). Statistically, this turns the target Q into a mean over its neighborhood, improving robustness and prediction accuracy.

# Value Functions

A value-function method is a typical deterministic algorithm: its policy selects the action with the largest Q value with probability 1. Choosing the maximum Q is essentially choosing the maximum advantage.

## Value Iteration

Policy iteration has two stages, policy evaluation and policy improvement. After switching to a Q-based deterministic policy, explicit policy improvement can be omitted because the largest Q already defines the policy. This is value iteration. Both policy iteration and value iteration fundamentally alternate estimation and improvement, and estimation always uses the Bellman equation. Value iteration estimates Q and does not require an explicit improvement step.
