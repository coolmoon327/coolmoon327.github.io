# Issues

1. Off-policy issue
   - Importance sampling
   - Estimate Q instead of estimating V
2. Q-value overestimation
   - Maintain two Critic networks and use the smaller Q estimate each time
3. Bias
   - PG has variance but is unbiased. After introducing γ\gammaγ, however, discounted reward is biased relative to the original Monte Carlo trajectory. Most RL methods learn discounted cumulative reward, so this bias is usually not the concern here.
