# AX86U Pro Firewall Configuration

**Problem analysis:** I enabled the router's firewall for security, but then found that many applications stopped working correctly. For example, Nginx could no longer reverse-proxy traffic and aria2 could not connect.

![ASUS AX86U Pro firewall settings](/assets/blog/generated/nas-import/asusax86upro-duan-kou-fang-xing/image-001.png)

**Solution:** Configure iptables manually. For example:

```
# 多端口
iptables -I INPUT -p tcp -m multiport --dports 8888,23455,23456,23457,23458,23453 -j ACCEPT
iptables -I INPUT -p udp -m multiport --dports 8888,23455,23456,23457,23458,23453 -j ACCEPT

# 单端口
iptables -I INPUT -p tcp --dport 6800 -j ACCEPT
iptables -I INPUT -p udp --dport 6800 -j ACCEPT
```

**Implementation:** Create or edit `firewall-start` under `/jffs/scripts/`, add the iptables configuration script, set its permissions to 755, and restart the router.
