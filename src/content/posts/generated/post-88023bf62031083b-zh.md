# AX86u Pro 防火墙配置

**问题分析**：因为安全原因，打开了路由器的防火墙，但是发现很多软件出了问题，比如 Nginx 无法正常反代、aria2 无法连接等。

![ASUS AX86U Pro 防火墙设置](/assets/blog/generated/nas-import/asusax86upro-duan-kou-fang-xing/image-001.png)

**解决方法**：手动设置 iptable。如：

```
# 多端口
iptables -I INPUT -p tcp -m multiport --dports 8888,23455,23456,23457,23458,23453 -j ACCEPT
iptables -I INPUT -p udp -m multiport --dports 8888,23455,23456,23457,23458,23453 -j ACCEPT

# 单端口
iptables -I INPUT -p tcp --dport 6800 -j ACCEPT
iptables -I INPUT -p udp --dport 6800 -j ACCEPT
```

**实施方案**：在 `/jffs/scripts/` 下新建/修改 `firewall-start` 文件，里面填上 iptable 配置脚本，修改权限为 755，重启路由器。
