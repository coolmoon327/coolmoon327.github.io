## Terminology

- **Episodic**

The state is reset after every T episodes—for example, returning to the initial state after hitting a wall in a maze.

For a non-episodic MDP, γ < 1 is required to avoid accumulating reward without bound.

- **Finite Markov Decision Process** *FMDP*

Most RL problems concern FMDPs: state S, action A, state transition P(st+1|stat), immediate reward function R(st, at, st+1), and discount factor γ.

- **Partially Observable Markov Decision Process** *POMDP*

### **Classification of Reinforcement-Learning Algorithms**

1. Value-function optimization—***dynamic-programming methods***

   When the model (S, A, P, R, γ) is known, dynamic programming can solve it.

   The main methods include policy iteration, value iteration, and policy search; the first two are the focus here.
2. Policy optimization—***policy-optimization methods***

   When model parameters (P, R, γ) are unknown, reinforcement learning solves the model-free MDP.

   The principal methods are Monte Carlo and temporal difference.

### **Monte Carlo Algorithms**

When calculating a value function, a Monte Carlo method replaces the expectation of a random variable with an **empirical average**.

Here, experience means conducting many trials with the policy and producing many episodes of data, where an episode is one trial. Because the interaction model between agent and environment is unknown, a Monte Carlo method estimates the value function through empirical averages. Whether the correct value function can be obtained depends on experience. **Obtaining sufficient experience is central to model-free reinforcement learning.**

[[formula] omitted: third-party image]

A Monte Carlo method must guarantee that every state can be visited. One approach is **exploring starts**, meaning that every state has some probability of serving as the initial state.

A soft exploration policy gives every action in the action set a probability greater than zero in every state. A typical soft policy is the [[formula] omitted: third-party image] policy.

Depending on whether the exploration policy—the behavior policy—and the policy being evaluated are the same, Monte Carlo methods are divided into on-policy and off-policy methods. Off-policy methods mainly use **importance sampling**. State transition P can be eliminated during importance sampling.

Compared with dynamic programming, a Monte Carlo method must wait for each trial to end, so learning is slow and inefficient.

DP and TD use a one-step prediction to calculate the current state-value function. Both use bootstrapping; the difference is that DP calculates the successor state from the model, whereas TD obtains the successor state through a trial.

During state evaluation, a greedy policy finds a’ that maximizes the value function at s’ and then updates the value function. ### **PPO**

PPO is a newer Policy Gradient algorithm. Policy Gradient is highly sensitive to step size, yet an appropriate step size is difficult to choose; if old and new policies change too much during training, learning suffers. PPO introduces a new objective that supports mini-batch updates over multiple training steps and addresses the difficulty of choosing a step size in Policy Gradient. TRPO is motivated by the same concern, but PPO is easier to solve.
