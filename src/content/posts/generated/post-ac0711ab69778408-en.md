# Writing Papers in VS Code

## Environment Requirements

- First, make sure the system has a LaTeX compilation environment.
  - `brew install --cask mactex-no-gui`
- Install VS Code, and download LaTeX Workshop from the extension marketplace.
- If you need forward and inverse search, use Skim as the PDF reader.
  - `brew cask install skim`
  - Select VS Code for Skim's PDF-TeX synchronization support.

## VS Code Configuration

- Edit VS Code's `settings.json` to configure the LaTeX compilation process.

```
{

    // 此处省略其他配置

    // LaTeX
    // 不在保存的时候自动编译
    "latex-workshop.latex.autoBuild.run": "never",
    // 编译工具
    "latex-workshop.latex.tools": [
        {
            "name": "xelatex",
            "command": "xelatex",
            "args": [
                "-synctex=1",
                "-interaction=nonstopmode",
                "-file-line-error",
                "-pdf",
                "%DOCFILE%"
            ]
        },
        {
            "name": "pdflatex",
            "command": "pdflatex",
            "args": [
                "-synctex=1",
                "-interaction=nonstopmode",
                "-file-line-error",
                "%DOCFILE%"
            ]
        },
        {
            "name": "bibtex",
            "command": "bibtex",
            "args": [
                "%DOCFILE%"
            ]
        }
    ],
    // 编译命令模板
    "latex-workshop.latex.recipes": [
        {
            "name": "xelatex",
            "tools": [
                "xelatex"
            ],
        },
        {
            "name": "xelatex*2",
            "tools": [
                "xelatex",
                "xelatex"
            ],
        },
        {
            "name": "pdflatex",
            "tools": [
                "pdflatex"
            ]
        },
        {
            "name": "xe->bib->xe->xe",
            "tools": [
                "xelatex",
                "bibtex",
                "xelatex",
                "xelatex"
            ]
        },
        {
            "name": "pdf->bib->pdf->pdf",
            "tools": [
                "pdflatex",
                "bibtex",
                "pdflatex",
                "pdflatex"
            ]
        }
    ],
    // 设置 latex-workshop.build 指令的默认命令，此处使用带有 bibtex 的编译过程
    "latex-workshop.latex.recipe.default": "pdf->bib->pdf->pdf",
    // 使能从 VSCode跳转到 Skim 里相应位置
    // external pdf viewer
    "latex-workshop.view.pdf.viewer": "external",
    "latex-workshop.view.pdf.external.synctex.command": "/usr/local/bin/displayline",
    "latex-workshop.view.pdf.external.synctex.args": [
        "-r",
        "%LINE%",
        "%PDF%",
        "%TEX%"
    ],

    // 使能从 VSCode 中直接打开 Skim
    "latex-workshop.view.pdf.external.viewer.command": "/usr/local/bin/displayline",
    "latex-workshop.view.pdf.external.viewer.args": [
        "0",
        "%PDF%"
    ],
}
```

- Edit VS Code's `keybindings.json` to configure keyboard shortcuts.

```
// 将键绑定放在此文件中以覆盖默认值
[
    {
        // 前向搜索
        "key": "cmd+shift+s",
        "command": "latex-workshop.synctex",
        "when": "editorTextFocus"
    },
    {
        // 使用默认 recipe 编译
        "key": "cmd+shift+b",
        "command": "latex-workshop.build",
        "when": "editorTextFocus"
    },
    {
        // 终止编译
        "key": "cmd+shift+t",
        "command": "latex-workshop.kill",
        "when": "editorTextFocus"
    },
    {
        // 选择其他 recipe 编译
        "key": "cmd+shift+e",
        "command": "latex-workshop.recipes"
    },
]
```

## BibTeX

- In the paper's `.tex` file, use `\bibliography{ref}` to specify the bibliography; `ref` is the filename of `ref.bib`.
- To compile LaTeX with BibTeX manually in a terminal, run:

```
pdflatex %DOCFILE%
bibtex %DOCFILE%
pdflatex %DOCFILE%
```
